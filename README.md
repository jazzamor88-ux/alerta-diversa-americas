# Alerta Diversa Américas

Aplicación Next.js para registrar y visualizar crímenes de odio contra personas LGBTIQ+ en las Américas.

## Alcance

- Interfaz multilingüe en español, inglés, francés y portugués.
- Formulario seguro de reportes.
- Endpoint `/api/reports` para recibir casos.
- Visualización pública anonimizada de casos de muestra.

## Desarrollo

```bash
npm install
npm run dev
npm run build
```

Usa `.env.example` como plantilla. No se versionan secretos reales.
